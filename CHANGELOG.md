# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-08-04

### Added

- Make `npx skills add asdlem/agent-product-ui-ux` the canonical installation path.
- Validate discovery and a complete installation through the pinned Skills CLI.

## [1.0.1] - 2026-08-04

### Fixed

- Make the Codex installation command fall back to `~/.codex` when `CODEX_HOME` is unset.

## [1.0.0] - 2026-08-04

### Added

- Canonical English skill for agent-product UI/UX design, implementation, review, and runtime verification.
- State, queue, approval, scrolling, focus, and contextual tool-workspace contracts.
- Synthetic interactive reference surface with clean and annotated screenshots.
- English and Simplified Chinese project documentation.
- Automated structure, privacy, asset, translation, installation, and evaluation-fixture validation.
