# Security

## Reporting

Do not open a public issue for a credential, private user data, or another sensitive disclosure. Use GitHub's private vulnerability reporting for this repository. If that channel is unavailable, contact the maintainer through the private contact method shown on their GitHub profile.

## Public-data boundary

This repository must contain only synthetic or owned examples. Reports that identify a real conversation, credential, private path, proprietary product asset, or other non-public material in the repository are treated as security issues.

Only the latest release is supported. Do not include sensitive material in reproduction steps, screenshots, logs, or evaluation fixtures.
